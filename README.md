# Nixoma - العملة الرقمية المستقبلية 🚀

موقع تعريفي لعملة Nixoma الرقمية، مصمم بتقنيات الويب الحديثة.

## المميزات 🌟
- تصميم متجاوب يعمل على جميع الأجهزة
- وضع النهار والليل
- واجهة مستخدم سلسة وعصرية
- أداء عالي وتحميل سريع
- دعم كامل للغة العربية

## التقنيات المستخدمة 💻
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## التثبيت والتشغيل 🔧
1. قم بنسخ المستودع:
```bash
git clone https://github.com/[your-username]/nixoma-website
```
2. افتح ملف `index.html` في المتصفح

## المساهمة 🤝
نرحب بمساهماتكم! يرجى اتباع الخطوات التالية:
1. قم بعمل Fork للمشروع
2. قم بإنشاء فرع جديد (`git checkout -b feature/improvement`)
3. قم بإجراء تغييراتك وحفظها (`git commit -m 'إضافة ميزة جديدة'`)
4. ارفع التغييرات (`git push origin feature/improvement`)
5. قم بإنشاء طلب دمج (Pull Request)
